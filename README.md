## 工程美学观

- **可读性优先**：让代码像文档一样自然，让协作成本更低。  
- **抽象克制**：只引入必要复杂度，避免过度设计。  
- **边界清晰**：用稳定接口隔离变化，用结构承载演进。  
- **长期主义**：今天的实现，要经得起未来迭代与重构。
